Todo List App :-
A modular todo list application built for The Odin Project.

What I Learned :-
I learned valuable lessons about using localStorage, splitting code into several files, and becoming familiar with ES6 class constructors instead of using plain functions.

My Opinion on AI :-
I wonder whether I am vibe coding. Although I didn't use AI to generate code, I was mostly guided by AI in the right direction. I used it because I had no one else to guide me, especially since I am deaf and struggle with complex English structures in web design topics filled with advanced concepts.

Moving Forward :-
I hope to become more familiar with these concepts in future projects. I believe it is not important to know every detail of how everything works; it is about how much impact you make in real-world applications, and I prefer learning over strictly sticking to rigid requirements.
